# Русская локализация filex

Полный русский языковой пакет для [filex](https://github.com/BRF-Tech/filex) — самостоятельно размещаемого файлового менеджера.

## Состояние перевода

- Версия каталога filex: **0.61.2**
- Переведено: **7 518 из 7 518 строк (100%)**

> Первая версия подготовлена с помощью машинного перевода. Перед использованием в критически важной среде рекомендуется проверить терминологию и сообщить о неточностях через Issues или Pull Request.

## Установка из GitHub

1. Откройте в filex: **Administration → Apps → Install an app**.
2. Выберите **GitHub repository**.
3. В поле **Repository** укажите:

   ```text
   Alexan1111t/filex-lang-ru
   ```

4. Поле **Ref (tag, branch or commit)** оставьте пустым для ветки по умолчанию либо укажите `main`.
5. Нажмите **Review permissions**, проверьте сведения и установите пакет.

Для установки по тегу сначала создайте GitHub Release, например `v0.1.0`, и укажите этот тег в поле **Ref**.

## Установка из файла

1. Скачайте `filex-app.json` из этого репозитория.
2. Откройте **Administration → Apps → Install an app → Upload files**.
3. Загрузите `filex-app.json` и подтвердите установку.

## Включение русского языка

После установки откройте настройки языка filex и выберите **Русский**. Если язык не появился сразу, обновите страницу браузера.

## Обновление перевода

При установке из GitHub выберите обновление приложения в панели filex. Для установки из файла скачайте новую версию `filex-app.json` и установите её повторно.

## Разработка и проверка

Требуется Node.js 18 или новее.

```bash
npm install
node scripts/pack.mjs build
node scripts/validate.mjs filex-app.json
```

Основной файл перевода: `translations/ru.json`.
